# Changelog

All notable changes to this project are documented in this file.

## [Unreleased]

## [0.2.0] - 2026-09-30

### Added

- Bookings: create a booking with overlap check and price calculation.
- Bookings: get by id, search by space and date, search by customer email.
- Contributing guide, architecture decision records, issue and pull request templates.

## [0.1.0] - 2026-09-30

### Added

- Venues API: create, update, get by id, list with city filter.
- Spaces API: add a space to a venue, list spaces of a venue, get by id.
- CI pipeline on GitHub Actions.
