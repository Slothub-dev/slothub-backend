# Architecture Decision Records

An ADR is a short document that captures an important architectural decision together with its context and consequences.
We write one when a decision is hard to reverse or not obvious from the code.

To add a new ADR, copy [template.md](template.md) to `NNNN-short-title.md` with the next number and open a PR.
Accepted ADRs are not edited; if a decision changes, write a new ADR that supersedes the old one.
