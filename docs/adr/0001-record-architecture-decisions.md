# 0001. Record architecture decisions

- **Status:** Accepted
- **Date:** 2026-03-02

## Context

Decisions made early in the project are often forgotten, and new team members have no way to learn
why things are the way they are. Re-discussing the same questions wastes time.

## Decision

We record significant architecture decisions as ADRs in `docs/adr`, using the format from
[Michael Nygard's article](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).

## Consequences

- New team members can read the history of decisions.
- Writing an ADR takes some time, so we only do it for decisions that are hard to reverse or non-obvious.
